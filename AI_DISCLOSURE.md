# AI-Assisted Development Disclosure

Book Pet is an AI-assisted open-source project.

OpenAI Codex has been used extensively as a development collaborator,
including:

- researching XTEINK X3 community firmware and development tooling;
- proposing firmware architecture and interaction designs;
- writing and revising C++ firmware, documentation, and release materials;
- running compiler builds, packaging firmware images, and checking release
  artifacts;
- operating the local flashing workflow and GitHub release process under the
  maintainer's direction.

The human maintainer defines the product direction, chooses which suggestions
to accept, connects and operates the physical hardware, evaluates the
experience on the X3, and decides what is published. Builds, static assertions,
checksums, GitHub Actions, and physical-device testing are used to validate
AI-assisted work, but they cannot guarantee that every defect has been found.

## What does not use AI

Book Pet does not run an AI model on the X3. Each pet's thoughts, moods, and
personality are generated by deterministic local rules. The released firmware
does not send prompts or pet data to OpenAI or any other cloud service and does
not require a network connection.

## Contributions made with AI

AI-assisted contributions are welcome. Contributors should:

- disclose meaningful use of generative AI in the pull request;
- review and understand the submitted code;
- verify that builds and relevant tests pass;
- identify whether changes were physically tested or compiler-only;
- avoid submitting copied material whose license or origin cannot be
  established.

AI assistance does not change authorship responsibility: contributors and
maintainers remain responsible for the code and documentation they publish.
