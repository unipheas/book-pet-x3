XTEINK X3 DEVELOPER EDITION

BOOK PET

A tiny, offline e-paper pet that eats pages. One safe first install, then future updates can happen from a phone or SD card.

Open this page in desktop Chrome, Edge, or another browser with Web Serial. This installer needs a secure HTTPS connection. First install requires a desktop or laptop with the X3 pogo-pin USB cable. iPhone and iPad browsers cannot perform the USB install.

First install

  1. Use an unlocked XTEINK X3 Developer/overseas edition.
  2. Charge it, connect the magnetic USB cable, and wake it.
  3. Press Install Book Pet and choose the X3 serial port.
  4. Choose the clean-install option when prompted and keep it connected.

Future updates

  • On Book Pet, open Menu → Updates.
  • Choose Phone / Browser for a no-app wireless update.
  • Or copy UPDATE.BIN to /BOOKPET on an SD card.
  • A failed update keeps the working firmware and pet save intact.

Before you flash

This replaces the current device firmware. It is not for X4, retail-locked X3 hardware, or other ESP32-C3 devices. Back up books or files you care about before a first install.

Recovery

Hold the front Back button while powering on to open recovery and updates. Book Pet can also restore the previous working firmware after an update.
